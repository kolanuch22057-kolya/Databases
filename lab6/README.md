Лабораторна робота 6: Міграції схем за допомогою Prisma ORM

1. Вступ
Метою роботи є вивчення механізмів міграції баз даних за допомогою Prisma ORM. Робота включає аналіз існуючої схеми PostgreSQL, внесення змін у модель даних (додавання таблиць, зміна та видалення полів) та застосування цих змін до реальної бази даних за допомогою інструментів міграції.

2. 
2.1. Ініціалізація та аналіз схеми
Проект було ініціалізовано командами npm init та npx prisma init. Налаштовано підключення до існуючої бази даних lab2 через файл .env. За допомогою команди npx prisma db pull було отримано початкову схему даних.

2.2. Внесення змін до schema.prisma
Відповідно до завдання, у файл схеми були внесені такі зміни:

Додано нову модель Review: для зберігання оцінок та коментарів до фільмів.

Модифіковано модель movie: додано поле isAvailable (boolean) для відстеження наявності фільму.

Видалено поле phone у моделі client: з метою мінімізації персональних даних.

2.3. Застосування міграцій
Для кожної зміни було згенеровано та застосовано міграцію за допомогою команди npx prisma migrate dev. Кожна команда створила SQL-файл у папці prisma/migrations, який автоматично оновив структуру таблиць у PostgreSQL.

4. Висновок
Під час виконання лабораторної роботи було опановано інструментарій Prisma ORM для керування схемою бази даних. Використання міграцій замість прямого написання SQL-запитів дозволяє безпечно та послідовно змінювати структуру БД, зберігаючи історію змін у системі контролю версій. Всі поставлені завдання виконані, працездатність оновленої схеми підтверджена.
